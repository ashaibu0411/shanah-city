Who can do what

Access requires sign-in, membership in Shanah Worship (Choir), and full group access (complete Before You Serve if the app shows it pending).

Role Open planner Build & publish plans Song library & rotation
Choir member Yes No View schedule only
Choir group leader (Leader on Manage tab) Yes Yes Yes
Admin Group (church app admin) Yes Yes Yes

Assistant leaders can manage regular members in Groups but cannot change worship leadership roles in the planner by themselves.

How to open the planner

  1. Menu — Tap Worship (♫) in the app (after choir access).
  2. Group calendar — Groups → Shanah Worship (Choir) → Calendar → Open planner.
  3. Web path — Open /worship while signed in.

Step-by-step: plan one service (leaders)

1. Pick the service

On Service plan, choose date and time:

  • 9:00 AM, 10:00 AM, 11:30 AM (Sunday)
  • 7:00 PM (Friday worship)

Shortcuts: Copy from last Sunday · Copy to time (same day, another slot).

2. Build the setlist

  • Add from library or Add song
  • Set title, key, BPM, segment (opener, worship, offering, etc.)
  • Order with Up/Down; expand song for charts, YouTube, part notes, practice stems

3. Rehearsal & calendar

  • Rehearsal date & time (push reminder ~24h before, if enabled)
  • Optionally link a choir calendar event

4. Team roster

  • Add members from the choir group
  • Set role (worship leader, singer, musician, tech) and part (soprano, keys, …)
  • Assign upload duty for songs & YouTube before service

Save, publish, and run sheet

Action What happens
Save draft Saves work; team still sees “Plan not published yet”
Publish for team Full plan visible; members mark prepared & ready
Unpublish Returns to draft (hides from team)
Run sheet Opens printable flow for stage / sound (after plan exists)

  • Team readiness — count of members who marked Ready

  • Approve pending member practice uploads in song workspace when needed

Schedule tab — monthly leader rotation

  1. Open Schedule (leaders only for editing).
  2. Add worship leaders to the rotation pool.
  3. Set default service time, Sunday vs Friday, weeks ahead, skip dates.
  4. Save settings → Generate schedule → Approve (notifies choir).

Members use the same tab as Team schedule (read-only) to see who leads upcoming services.

Song library (leaders)

  • Search and maintain reusable songs (key, BPM, CCLI, notes)
  • Paste YouTube links; upload charts once
  • Add to plan on future Sundays

Choir calendar & absences

Groups → Shanah Worship (Choir) → Calendar — events, rehearsal dates, unavailability requests (leaders approve time away).

What choir members should do

  1. Open Worship → Service plan after the leader publishes.
  2. Read rehearsal notes and setlist (keys, charts).
  3. Use My part for their line (soprano, keys, etc.).
  4. Mark prepared on each song, then Mark myself ready.
  5. Use Rehearsals for uploaded recordings.

Troubleshooting

Issue Fix
No Worship in menu Join choir; finish Before You Serve if pending
