# Shanah City Design System V1 — proposal

Status: exploratory, pending visual approval. Applies to app and public website. Preserve functionality, church logo, authentic photography and existing routes.

## Visual direction
Warm editorial, not a generic technology dashboard. Light canvas #FAF9F6, surface #FFFFFF, ink #19283B, action #345DA7, decorative gold #A58A58. Dark canvas #111418, surface #1C222A, text #F3F3EF, action #8EAFE8, decorative gold #BCA475. Gold is decorative until contrast is verified. Verify against actual logo before adoption.

Use existing font assets initially; clear hierarchy, readable body text, restrained weights. Use 4/8px spacing rhythm, 16px mobile gutters, consistent alignment. Prefer flat sections and dividers to nested cards. No default gradients, glow, glassmorphism, excessive pills or ornamental icons. Use authentic church photography with consent and meaningful crops. Use motion only for state changes, respect reduced motion. Maintain WCAG AA contrast, visible keyboard focus, accessible names, and 44px touch targets.

## Rollout
1. Inventory current homepage, public website, shared theme and navigation.
2. Produce separate mobile and desktop previews in both themes.
3. Review with owner before applying global tokens.
4. Migrate community, devotions, events, ministry and leadership surfaces incrementally.
5. Run existing regression tests, accessibility checks and visual comparisons before production.
