# Story music catalog expansion roadmap

**Strategy:** Hybrid **licensed API** (breadth) + **church_authorized** (regional gospel gaps). All expansion requires rights intake or vendor contract.

## Phase A — Pilot (0–3 months)

| Region | Target | Source |
|--------|--------|--------|
| Ghana | 3–5 tracks | Church-authorized pilot |
| Nigeria | 3–5 tracks | Church-authorized pilot |
| US gospel/CCM | 5–10 | Licensed API **if verified** |
| Instrumental worship | 3–5 | Licensed API or PD hymns |

**Exit:** Staging pilot sign-off; top 10 legacy ids mapped.

## Phase B — Core Africa & Caribbean (3–9 months)

| Region | Target | Notes |
|--------|--------|-------|
| South Africa | 5+ | Joyous Celebration–class catalogs via deals |
| East Africa (KE, TZ, UG) | 5+ | Church-authorized primary |
| Caribbean | 3+ | JM/TT diaspora; church-authorized |
| Latin America | 5+ | ES/PT worship; licensed + local |

## Phase C — Global worship (9–18 months)

| Region | Target |
|--------|--------|
| North America | Expand CCM/worship via licensed collections |
| Europe | UK/EU worship; hymns |
| Asia | KR/JP/PH worship as partnerships allow |

## Metadata standard (every track)

`country`, `language`, `genres[]`, `artist`, `title`, `territory`, `licenseEndDate`

## Discovery UX

- Filters already in hybrid picker: country, language, genre, text search.  
- Add curated playlists per region (JSON or CMS later).

## Success metrics

- Attach success rate (preview OK → post OK)  
- Playback success rate (stream 200)  
- Support tickets re: music  
- Legacy id unavailable rate trending down
